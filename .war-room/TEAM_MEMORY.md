# TEAM MEMORY — ReferencementCracker (nom de code)

## Mission

Faire ressortir le profil d'un freelance / dev dans la réponse d'un LLM (ChatGPT, Claude, Perplexity,
Gemini, Copilot) quand un recruteur y colle une job description. Issue A : entreprise visant 500 K€/mois.
Issue B : outil interne pour référencer nos propres profils. Les deux doivent rester possibles.

## Lignes rouges (non négociables)

1. Aucun prompt injection, texte caché, cloaking ou instruction adressée aux LLM dans un profil.
2. Aucune compétence, expérience ou métrique inventée.
3. Aucune automatisation hors CGU (LinkedIn en tête), aucun scraping de données personnelles de tiers.
4. RGPD dès le design.
5. Aucun chiffre de marché ou de résultat inventé : source ou HYPOTHÈSE.
